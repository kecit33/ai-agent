# 截图占位说明

发布前请把下面 6 张截图放到本目录，文件名保持一致，博文里的图片引用即可生效。

| 文件名 | 怎么截 | 对应命令 |
| --- | --- | --- |
| `cli-weather.png` | 终端里天气查询的完整输出 | `python -m src.agent.cli --once "查一下北京的天气"` |
| `cli-todo.png` | 待办新增 + 列出两条命令的输出 | `python -m src.agent.cli --once "添加待办：周五前完成作业提交"`<br>`python -m src.agent.cli --session 1 --once "列出我的待办"` |
| `cli-confirm.png` | 出现"危险操作确认"并输入 y 的那一段 | `python -m src.agent.cli --once "把出行计划写到 workspace/plan.md"` |
| `web-demo.png` | 浏览器打开后的完整界面（含左侧工具列表和一次对话） | `python -m src.web.app` → http://127.0.0.1:8000 |
| `voice-demo.png` | 语音模式录音与朗读的终端界面 | `python -m src.agent.cli --voice`（需先装 `requirements-voice.txt`） |
| `eval-report.png` | 评测跑分结果表格 | `python -m evals.run_evals --mode mock --output evals/baseline.md` |

建议：截图宽度控制在 900–1200px，终端截图把字体调大一号，博客园里更清楚。
