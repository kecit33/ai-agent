# 运行指南：别人拿到这个项目怎么跑起来

> 面向第一次拿到本仓库的人。全程照抄命令即可，Windows / macOS / Linux 三套命令都给了。
> 预计耗时：装依赖 2–5 分钟，跑通第一条对话 1 分钟。

---

## 0. 前置条件

| 项目 | 要求 | 检查命令 |
| --- | --- | --- |
| Python | 3.10 及以上（本项目实测 3.13） | `python --version` 或 `python3 --version` |
| Git | 任意版本 | `git --version` |
| 网络 | 需要访问 GitHub 与 DeepSeek（**只在用真实模型时需要**） | — |
| DeepSeek API Key | **可选**。没有也能完整演示（见第 4 节的 Mock 模式） | — |

---

## 1. 获取源码

```bash
git clone https://github.com/kecit33/ai-agent.git
cd ai-agent
```

> 如果下载的是 ZIP 包，解压后 `cd` 进 `mcp-agent` 这一层（能看到 `requirements.txt` 的那一层）。**后面所有命令都必须在这个目录下执行**，否则会报 `ModuleNotFoundError: No module named 'src'`。

---

## 2. 建虚拟环境并装依赖

**Windows（CMD / PowerShell）**

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
chcp 65001                    :: 中文乱码时执行这一条
```

**macOS / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

看到命令行前面出现 `(.venv)` 说明虚拟环境已生效。核心依赖只有 5 个（openai、httpx、fastapi、uvicorn、python-dotenv），不装语音包的情况下 1 分钟内装完。

> **PowerShell 报"禁止运行脚本"**：以普通用户执行
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，然后重新 `.\.venv\Scripts\Activate.ps1`。

---

## 3. 配置密钥（二选一）

### 3A. 有 DeepSeek Key（真实模型）

```bat
copy .env.example .env          :: Windows
```

```bash
cp .env.example .env            # macOS / Linux
```

用记事本或任意编辑器打开 `.env`，改这一行：

```ini
LLM_MODE=openai
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-你的真实密钥
LLM_MODEL=deepseek-chat
```

`LLM_API_KEY` 与 `DEEPSEEK_API_KEY` 两个名字都认，填一个即可。

### 3B. 没有 Key（Mock 模式，推荐验收/演示用）

同样复制出 `.env`，只需保证：

```ini
LLM_MODE=mock
```

规则模型会把"查天气""加待办""读文件"这类句式的完整链路跑通（MCP 握手 → 工具调用 → 结果整合 → 多轮记忆），**只是语义理解退化成关键词匹配**。日志里会如实标注 `degraded`。

> 安全提醒：`.env` 已在 `.gitignore` 中，**真实密钥不要提交到 GitHub**，也不要贴进聊天窗口或作业文档。

## 4. 运行：三种方式

### 4.1 命令行（最稳，推荐第一次用）

```bash
python -m src.agent.cli                              # 进入交互式对话
python -m src.agent.cli --once "查一下北京的天气"       # 执行一句就退出
python -m src.agent.cli --session 1                  # 指定会话，记忆可复用
```

交互式里的常用命令：输入 `/help` 看全部，`/tools` 看工具清单，`/exit` 退出。
第一次建议直接复制这三条验收：

```bash
python -m src.agent.cli --once "查一下北京的天气"                        # 外部 API
python -m src.agent.cli --once "添加待办：周五前完成作业提交"              # 数据库
python -m src.agent.cli --once "统计一下 workspace/sales_demo.csv"       # 文件处理
```

看到类似下面的输出就说明全链路通了：

```
  ✅ weather_get (2950ms) args={'city': '北京', 'days': 3}
小枢 > 北京当前小毛毛雨，气温 10.6℃……
[trace=07823aea997441bc 步数=1 停止原因=模型给出最终答复 耗时=3033ms]
```

### 4.2 网页界面（演示最好看）

```bash
python -m src.web.app
```

浏览器打开 <http://127.0.0.1:8000>。左侧是工具清单（从 MCP Server 动态拉取），右侧对话区会把每次工具调用展开成卡片（名称、参数、耗时、成败），遇到写文件会弹确认框。

> 端口被占用时改用：`python -m uvicorn src.web.app:app --port 8010`

### 4.3 语音模式（可选加分项）

```bash
python -m pip install -r requirements-voice.txt
python -m src.agent.cli --voice
```

回车开始录音 → 本地 Whisper 转写 → Agent 执行 → 离线 TTS 朗读。**没装语音依赖会自动退回文本模式**，不影响其他功能。

## 5. 批量演示与评测

```bash
bash evals/run_demo.sh                                   # 12 条真实模型演示，结果写入 evals/demo_results.md
python -m unittest discover -s tests                     # 16 条单元测试
python -m evals.run_evals --mode mock --output evals/baseline.md   # 23 条评测集
```

三条命令都不需要额外的密钥（评测默认走 Mock 基线），可以放心在没网的机器上跑。

## 6. 运行时产生了哪些文件

| 路径 | 内容 | 能否删除 |
| --- | --- | --- |
| `.data/agent.db` | SQLite：对话历史、待办、长期事实 | 可以，删了就是全新状态 |
| `.data/logs/agent.log` | 单行 JSON 日志（含 trace_id，密钥已脱敏） | 可以 |
| `workspace/` | 文件工具的沙箱目录，示例数据在此 | 示例数据建议保留 |
| `.env` | 你的密钥 | 别删，也别传 |

想恢复干净状态：

```bash
rm -rf .data        # macOS / Linux
```

```bat
rmdir /S /Q .data   :: Windows CMD
```

## 7. 常见报错排查

| 现象 | 原因 | 解决办法 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'src'` | 不在项目根目录，或没用 `-m` 方式启动 | `cd` 到能看到 `requirements.txt` 的目录，用 `python -m src.agent.cli` |
| 客户端报"无法解析的 JSON-RPC 消息" | 有人往 MCP Server 的 stdout 打了日志 | 检查自定义工具里有没有 `print`，日志必须走 `logging` |
| 中文乱码 | Windows 默认 cp936 | 执行 `chcp 65001`，或设环境变量 `PYTHONUTF8=1` |
| 401 / `Unauthorized` | Key 填错、过期或余额不足 | 检查 `.env`；程序会自动降级 Mock 并在日志标注 `degraded`，不会崩 |
| 天气一直超时 | 网络不通或被代理拦截 | `weather_get` 走 Open-Meteo，需要能访问该域名；也可关掉 `ALLOW_HTTP_FETCH=false` |
| 端口 8000 被占用 | 已有进程占用 | `python -m uvicorn src.web.app:app --port 8010` |
| 写入文件报"路径越界" | 工具只能访问 `workspace/` | 这是**设计正确的表现**，把文件放进 workspace 再操作 |
| 提示注入测试没拒答 | 用的 Mock 规则模型 | 真实 DeepSeek 会拒答；Mock 的拒答是硬编码规则，只覆盖评测里的句式 |

排查不了时看日志：`.data/logs/agent.log`，每一行都有 `trace_id`，按它就能串起一次完整请求。

## 8. 安全须知（给别人跑之前请先看）

1. **密钥只放 `.env`**，代码里没有任何硬编码密钥，日志写入前对密钥/手机/邮箱/身份证统一脱敏；
2. **文件工具锁在 `workspace/` 沙箱内**，越界一律拒绝——这不是限制，是保护；
3. **写文件、删待办、执行代码会先弹确认**；宿主没提供确认回调时**默认拒绝**而不是放行；
4. `code_run_python` 默认关闭（`ALLOW_CODE_EXEC=false`），它不是安全沙箱，仅供教学演示；
5. `http_get_json` 未做域名白名单，不要在内网环境开放该工具。
